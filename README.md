# 花笺：会听歌、会读歌的歌词动画

> 它不是一套固定的动画模板，而是一位坐在你播放器里的「导演」：一边听节拍，一边读歌词，给每一首歌现场排一部只属于它的歌词短片。

## 为什么不一样

**🎧 实时听出这首歌的心跳**

不用下载音频，花笺直接从 Folia 的实时频谱里听出 BPM、拍点和大小调，约 20 秒锁定（合成测试误差 0.1 BPM 以内），听过的歌下次一开场就有，而且越听越准。

**🧭 按速度自动换一整套镜头语言**

- 92 BPM 以下的慢歌：**流光**、**云阶**，字像水面的光一样缓缓浮起、错落成阶；
- 112 BPM 以上的快歌：加入**心象**，每个字化作一片碎片，沿起伏的路径散开游动；
- 每秒唱 5.5 个字以上的说唱：切到**浮名**，整段歌词铺成一张巨大的纸，镜头逐句飞过去；
- BPM 一听准，还没出场的镜头会立刻按新的节奏重新编排。

**🎬 AI 导演为每首歌单独写分镜**

AI 把整首歌词读一遍，判断它是心碎还是热血、是冷是暖，然后给每个段落挑版式、动作性格、氛围（雨、雪、落花、萤火、星空……）、烟花强度和要放大的关键词。再结合听出来的 BPM 和调性，主歌、副歌、气口、尾声各有各的样子，最后一次副歌自动升格为全曲高潮。

- 伤感的歌：字只从模糊里淡入淡出，线香花火在高潮处噼啪燃尽；
- 欢快的歌：字弹跳落定，烟花提前升空，正好在那个字唱出来时炸开；
- 鼓点上的镜头冲击、抖动、色差都卡在真实拍点上，小节第一拍最重。

**🎲 同一首歌，几乎不会出现两次一样的画面**

13 种整组排字、3 种整页、12 种线描徽章、多种段落和镜头转场轮流组合，相邻三个镜头不重复同一种排法，重复的副歌也会换一种排法再来。

## ⭐ 强烈建议接上 AI 接口

不配 AI 也能用：本地导演会根据歌词、歌名和主题来猜情绪。但它只是猜，AI 是真的读懂了歌词。在 30 首歌、8 种情绪的评测集里：

| | 情绪判断落在正确范围 |
|---|---|
| AI 导演 | **97%～100%** |
| 本地导演 | 约 73% |

接上 AI 以后，伤感歌不会被误当成快歌去放烟花，关键词放大得更准，每段的编排也更贴合歌词在说什么。

- 每首歌只问一次，结果存在本地，同一首歌以后不再花钱；还会提前分析队列里的下一首。
- 任何兼容 OpenAI 的接口都能用（DeepSeek、通义、Kimi、OpenAI……），也支持本机的 Ollama 和 LM Studio，完全离线、零费用。
- 只发送歌名、歌手、专辑、歌词、主题名和听出的 BPM / 调性，密钥由 Folia 加密保存。

## 安装与开启

1. 把压缩包里的 `huajian` 文件夹放进 `%APPDATA%\Folia\mods\`（最后是 `%APPDATA%\Folia\mods\huajian\mod.json`）。重启 Folia，或者在 **设置 → 模组** 里重新加载，然后启用「花笺」。它需要两个权限：数据文件（用来记住每首歌的分析结果）和网络（用来调用 AI）。需要 Folia 0.7.22 及以上、0.8 以下。
2. 在歌词样式里选择 **花笺**。
3. **接上 AI（推荐）**：**设置 → 模组 → 花笺**，选服务商，填模型名和 API 密钥，然后在命令面板运行 **花笺：测试 AI 连接**。服务商的写法和 AI 歌词动画导演 Plus 一样。

## 它怎么工作

```
换歌 → 读歌词 → 分段（主歌 / 副歌 / 气口 / 尾声）
     → 导演给出分镜方向：整首的明暗、能量、冷暖、配色、氛围元素，
       以及每段的版式、元素、火花强度、要放大的关键词
     → 本地排期器把方向变成精确时间表：每段几点出场，每朵烟花几点升空、正好在哪个字上炸开
     → 舞台按歌曲时钟逐帧画出来
```

- **AI 只当导演，不画画**：每首歌只调用一次，结果记在数据文件里，同一首歌以后不再花钱。播放当前这首时，会提前把队列里的下一首分析好。
- **AI 结果晚到也不会跳画面**：已经唱到的段落保持原样，还没开始的段落才换成 AI 的安排。
- **伤感的歌不会放烟花**：整首明暗低于 0.4 时，烟花一律换成线香花火。这条在代码里写死了，不靠 AI 自觉。

## 视觉语言

**镜头分两种。**

- **整组排字**（参照商籁）：除诗稿和竖排外，每段切成若干镜头，每个镜头 1～4 句（不超过 6 秒、12 个词）。镜头里所有的词排成一张版面：
  - **按句读排**：
    - 每句先切成短语。中文看歌词里的空格；英文看标点，最多三个词一组。
    - 换行只发生在短语之间，短语内部不拆开。
    - 分词切出来的单字不单独成块："的、了、吗"这类助词并到前一个词，其他单字并到后一个词。
  - **主词**：挑一个放到其他字的 2～5 倍，就留在它所在的短语里，前后的字照常连着，读起来还是一句完整的话。
    - 优先选关键词；其次选不超过 5 个字的整个短语（如"雨停以后""说成明天"）；再次选 2～4 个字的实词。
    - 不选"的话""了吗"这类虚词开头的词，也不选"你的""我的"这类以"的"结尾的短词。
  - **长句**：不带空格、8 个字以上的整句，在中间附近的词边界拆成两段（如"心跳比鼓点 / 还要急"），版面就有上下两行可排。同一行里拆开处不留空隙。
  - **分词失灵时**：分词器把一句切成一长串单字时，每两三个字分一块，不再整串并成一个；这种块不优先当主词。
  - 所有字都横排，竖排只用在"竖排整页"里。
  - 每个词唱到时才出现：快歌从各自的方向滑进来落定，伤感歌原地淡出。
  - 镜头略微放大，整个镜头里只做很慢的推近和微漂，不追着词跑。
- **整页**：诗稿和竖排两种段落是一整页。每句唱到时写上去并留在页上，唱过的句子退淡，镜头只朝当前句缓缓偏一点。
  - 诗稿页有三种样式：沿页边线、左右交替（像对话）、逐行缩进。
  - 一首歌只有第一段诗稿式主歌用整页，后面的诗稿段落改用整组排字轮换，避免主歌总是一行行往下排。
  - 相邻三个镜头不重复同一种排法。

| 排法 | 样子 |
|---|---|
| 环绕 | 按阅读顺序一行行居中堆叠，主词所在的短语单独一行放大 |
| 冲击 | 同环绕，主词放到约 5 倍，用在副歌和高潮 |
| 杂志栏 | 同样的行，左对齐（或右对齐），离主词行越远缩进越多 |
| 横带 | 整个镜头排成一行，主词在原位放大（只用于字少的镜头） |
| 散布 | 其余短语围着主词那一行、从左上开始按唱的顺序找空位（只在热闹的段落偶尔用） |
| 小诗 | 安静的排法：每句一行，左对齐，像一首短诗，主词在行内放大 |
| 阶梯 | 一行行往下，每行比上一行再错开一步，像台阶 |
| 对角两端 | 主词之前的字左上对齐，主词居中放大，之后的字右下对齐 |
| 侧栏 | 主词大字靠一侧，后面的字排成旁边一栏短行，前面的字压在主词上方 |
| 大小交替 | 每个短语一行，一大一小、一左一右交替，像标题排版 |
| 流光（借鉴 Folia 流光） | 每句一行大字居中，每个词各带一点上下错位、倾斜和大小；唱到的词微微亮起放大，唱过后再转一个角度，整行轻轻浮动 |
| 云阶（借鉴 Folia 云阶） | 每个短语一块，左右错落着往下排，像云中台阶，块旁一条细引导线；没唱到的块小而淡，唱到时长到全尺寸，唱过后左右交替倾斜 |
| 心象（借鉴 Folia 心象） | 每个字（英文是每个词）一片碎片，从左到右沿起伏的路径散开、各自倾斜；唱到时放大，唱过后向上漂开，所有碎片都在轻轻游动 |
| 浮名（借鉴 Folia 浮名，整页） | 整段歌词铺在一张比画面大的纸上，每句大小、左右、倾斜各不同，镜头逐句飞过去，唱过的句子留在原处变暗 |

| 凝彩排字（单句） | 挑一个长词放大到约 1.5 倍，其余按短语统一缩小；只在短语之间换行，每行略微错开和倾斜，带墨色投影 |
| 巨字（单句） | 关键词占满画面，其余小字托在上下 |
| 诗稿（整页） | 整段沿一条页边线排下来，每句到来时页边打一个记号 |
| 竖排（整页） | 整段中文从右往左成列，顶端对齐，用宋体，配稿纸竖格 |

**按节奏自动切换**：

- 每段先判断快慢：
  - 听出了 BPM 就看 BPM：112 以上算快，92 以下算慢。
  - 还没听出来时看歌词密度：每秒唱几个字，英文一个词约算 1.8 个字。
- 每秒 5.5 个字以上算说唱，主歌整段用浮名。
- 慢歌、伤感歌多用流光和云阶；快歌加入心象。
- 伤感歌里这几种的倾斜、缩放、漂移都只有原来的三分之一，不用心象。
- BPM 第一次听准时，还没出现的镜头会按新的快慢重新安排。

**背景**（参照商籁）：每个镜头背后有一幅线描，用一粗一细两层线条画，随镜头长出来、慢慢转动。

- **徽章**，共 12 种：刻度圆、套叠菱形、六边形、原子轨道、行星环、雷达、取景框、珠串轨道、月相环、花瓣曼陀罗、生命之花、星座连线。伤感歌只用其中安静的 6 种。
- **杂志网格**：杂志栏排法配全屏细网格和一个粗内框。
- **五线谱**：横带排法配五线谱，每唱到一个词，对应的音符亮起。
- **小方块**：小诗配几个依次出现的小方块。
- **辅助线**：主词周围再加一种：角括号或线框、带十字的圆环、转成菱形的方框、上下两道拱、跟着演唱长出的下划线。

画面最底层是三团按调色板着色的柔光，随时间缓缓游走。

**字的颜色**：

- 正文用主题的文字色。
- 关键词优先用 Folia 主题自带的关键词配色（`wordColors`），由 Folia 自己的匹配函数找出位置，和内置模式显示的一致。
- 主题没有配色表时，才用花笺 AI 导演挑的关键词，涂主题的强调色。
- "变色"这个演唱动作只在唱到时闪一下强调色，唱完褪回原色。

**重复的副歌**沿用第一次的动作，但换一种排法和一幅徽章。最后一次副歌是全曲高潮：只用冲击、散布、环绕，镜头更近，快歌闪白或冲镜开场，伤感歌漏光。

**转场**：

- **段落之间**（参照凝彩和商籁）：
  - 色带擦除：一条带尖角的色带横扫全屏，盖住上一段、露出下一段。
  - 整屏平移：新旧两段像一条长卷连着滑过去。
  - 模糊溶解：旧段一边放大一边虚掉，新段从虚到实。
- **段内镜头之间**：多数用商籁式的快速模糊切换（约 0.2 秒），也会用甩镜、推进、闪切、故障。

伤感歌只用模糊溶解、慢速平移和溶解。

**伤感歌不做动感特效**：不管性格是什么，字只会从模糊里淡出、墨晕或轻轻漂入；唱的时候只有微光和呼吸；退场是淡出或上飘；字用常规字重。没有弹跳、盖章、闪白和抖动，镜头不倾斜，也不随鼓点冲击。情绪的起伏靠字号、排法、光和线描来表现。

动态分四种性格，由 AI 按段落指定，或者由本地按能量和明暗来判断：

| 性格 | 进场 | 演唱 | 退场 | 运镜与转场 |
|---|---|---|---|---|
| 静 | 墨晕、漂入、雨落、对焦、聚拢、浮起 | 微光、呼吸、涟漪 | 上飘、溶解、下沉 | 缓推缓拉、漂移，溶解或漏光转场 |
| 抒 | 挤压升起、侧滑拖影、翻转、波浪、对焦 | 鼓起、微光、涟漪、变色 | 上飘、溶解、滑走、收缩、坠落 | 推、摇、升，推进或甩入 |
| 烈 | 盖章、冲镜、拉伸、螺旋、乱码解码 | 闪亮、鼓起、颤动、变色 | 溶解、四散、冲过镜头、坠落 | 推、滚转、冲击，闪白、故障切换、冲入 |
| 燃 | 弹出、落地回弹、盖章、爆开、故障、弹簧 | 弹跳、跳起、颤动、闪亮 | 四散、甩出、升腾、收缩、闪烁 | 冲击、滚转，甩镜、闪切、色差 |

（伤感歌不受这张表约束，见上一段。）

动作都带挤压拉伸、过冲和弹簧回弹。字的出场顺序也有讲究：

- 顺序、倒序都有；
- 变焦和爆开从中间向外出；
- 乱码和故障按随机顺序出。

其他装饰：页边线和记号（诗稿）、稿纸竖格（竖排）、漏光。

重拍时，镜头会冲击、抖动，并带一点色差，力度按性格不同：静的段落完全不受影响，燃的段落最强。

| 元素 | 用法 |
|---|---|
| 浮尘、雨丝、飘雪、落花、萤火、余烬、星空 | 整首或单段的氛围，段落之间平滑交叉淡入淡出 |
| 线香花火 | 伤感歌的高潮：一点火珠噼啪分叉，燃尽后火珠落下 |
| 烟花 | 欢快段落：牡丹、菊、柳、环四种弹型，提前升空，正好在词上炸开；实时鼓点也会追加小烟花 |
| 字化为光 | 一句唱完淡出时，字里飘出余烬、火星或光点 |

另外还有片头字卡（歌名、歌手、作词作曲）、胶片颗粒、暗角，镜头会随音乐轻微呼吸。

## 节奏与调性（边播边听）

花笺会从 Folia 的实时频谱里听出整首歌的速度（BPM）和调性（大调、小调）。用的是公开接口，本地歌曲、在线歌曲都适用，不用下载音频。

- **BPM**：
  - 把每帧的频谱起音按歌曲时间排在网格上，用自相关找周期（参考 bpm-style-director，MIT），再用整首的起音精修。
  - 合成测试里，62–174 BPM 的误差在 0.1 BPM 以内，拍点相位误差约 30 毫秒以内。
  - 第一次听约 20 秒就能锁定。
- **调性**：每个音在 C5–B7 范围内各取一个频段，只统计明显高出周围的谱峰，整首累积后和 Krumhansl 大调、小调音级分布比对。没有明确音高的歌（纯鼓点、噪声）不会报调性。
- **用途**：
  - 一旦对上拍，重拍时的镜头冲击、抖动、色差和小烟花都卡在拍点上，小节第一拍最重。没对上拍时，退回用瞬时起音。
  - 本地导演判断能量时会参考 BPM 和响度，大调、小调也会轻微影响明暗判断。
  - 听出来之后再问 AI，会把这些信息一起发过去。
  - 结果按歌曲存进数据文件（`aud:` 项），重听时一开场就有，还会越听越准。
- 打开「显示导演信息」可以看到当前的 BPM、调性和已经听了多少秒。

## 设置

在歌词样式里选中花笺，模式下方会出现这些设置：

- **动感**：字的起伏、镜头呼吸、鼓点反应的幅度。
- **粒子密度**：调到 0 就不显示粒子。
- **字号**
- **字体**：跟随主题 / 宋体 / 黑体。巨字和片头的歌名始终用宋体。
- **版式装饰**：线描徽章、网格、五线谱、辅助线等。
- **胶片颗粒**
- **画质**：
  - 自动：电脑吃力时自动减少粒子。
  - 高
  - 省电：限制在 30 帧。
- **显示导演信息**：左下角显示 AI 的判断、当前版式和每帧耗时。

命令面板里有四条命令：

- 花笺：测试 AI 连接
- 花笺：让 AI 重新分析这首歌
- 花笺：AI 怎么理解这首歌
- 花笺：AI 用量

## 性能

- 只有一张 WebGL 画布，粒子总共只占 2 次绘制调用。歌词时钟不动时不重绘，暂停时完全不占用。
- 所有粒子和动画都是歌曲时间的公式，不逐帧模拟。所以拖动进度条、暂停、导出视频时，画面都能精确对上。
- 每句歌词的镜头提前约 2 秒在后台搭好。搭建分成小步，每帧最多做约 3 毫秒：排版、逐批画字、画发光、上传显卡、建精灵、逐个装饰。所以换句时不会突然卡一下。重复的副歌直接复用已画好的字形。
- 字的发光层以一半尺寸、按屏幕倍率绘制再放大，后期滤镜跟随屏幕分辨率渲染，所以高分屏上也清楚。后期着色器在换歌时就预先编译好。
- 动画用自己的平滑时钟：每帧按真实流逝时间前进，再慢慢贴合 Folia 的歌词时间。宿主时间一跳一跳的时候，画面也照样顺滑。
- 实测（测试浏览器，没有显卡加速，约 80 秒热血歌，3223 帧）：
  - 中位数每帧 0.6 毫秒，99% 的帧在 1.9 毫秒以内；
  - 只有 2 帧超过 8 毫秒，分别是歌曲开头和烟花齐放的那一刻。
- 打开「显示导演信息」可以看到平均和峰值帧耗时。
- 帧耗时持续超过 7 毫秒时，会自动减少粒子并关掉颗粒。

## 隐私

只把歌名、歌手、专辑、歌词、Folia 主题名和听出的 BPM / 调性发给你配置的接口。密钥由 Folia 加密保存。

## 开发

```
node dev/build.mjs            # 把 src/ 合成 huajian/client.mjs
node dev/build.mjs --install  # 合成并复制到 Folia 的 mods 目录
node dev/unit.mjs             # 歌词分析、提示词、校验、排期的自检
node dev/serve.mjs            # 测试台：http://localhost:5178/dev/harness.html
```

测试台的参数：

- `song=ballad|anthem|lanterns`：选择三首自写测试歌（伤感、热血、英文）。
- `t=秒`：画面停在这个时间点。
- `play=1`：从 t 开始播放。
- `day=1`：日间主题。
- `ai=0`：只用本地导演。
- `showDirector=1`：显示导演信息。

键盘操作：空格暂停或播放，←/→ 跳 5 秒。

评测集（M1）：
- `node dev/build.mjs --dev --install` 装的是开发版，命令面板里多两条：「花笺（开发）：运行评测集」和「花笺（开发）：重新问 AI 并运行评测集」。
- 评测集是 30 首歌（`src/eval-set.mjs`，只存歌名和歌手），分 8 类：伤感、抒情、欢快、热血、悲伤快歌、说唱、纯音乐、长篇。歌词运行时从 Folia 的在线音源现取。
- 每首歌会同时跑 AI 导演和本地导演，检查两件事：情绪判断有没有落在这一类的范围内；排期有没有违规（伤感歌放烟花或用"燃"、副歌比主歌还平、非中文用竖排、AI 漏段落）。
- AI 的回答按"歌词 + 提示词"缓存，重跑不花钱；改了提示词会自动重新问。报告存在模组数据文件的 `evalLast` 项。
- 正式发布用 `node dev/build.mjs`，不含评测集和评测代码。

稳定性测试：
- 在测试台的控制台运行 `await __fuzz(60)`，会在 60 秒里随机跳转、暂停、切主题、隐藏歌词、改大小、重新挂载、开关预览画布，最后返回期间的报错。
- 地址加 `dpr=1.5` 可以模拟高分屏缩放，加 `coarse=0.25` 可以模拟一跳一跳的宿主时钟。

花笺在 Folia 里如果出现渲染错误，会自动恢复，并把前几次错误的完整堆栈记进模组数据文件（`%APPDATA%\Folia\mods-data\huajian\mod-data.json` 的 `diag` 项），方便排查。
